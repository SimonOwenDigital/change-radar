Power BI introduces custom data app creation in preview

Instant Summary:

Custom data apps let report authors build small interactive apps on top of their semantic models, in preview. Authors start from a template, connect it to a model and share it with the same permissions as the report. Admins can turn the feature off at tenant level. More detail will follow in the product documentation during the preview.

Azure SQL expands modernisation options

Azure SQL adds new migration paths and local development options for database teams. The changes cover assessment tools, a local emulator and improved resiliency settings for production workloads, with general availability planned for later in the year. None of it touches the products that Change Radar watches.

Autopilot is rolling out to Frontier customers

Autopilot is a long-running agent for personal productivity with its own identity, memory and access to tools. It can follow up on threads and run recurring work, and admins can see and manage it. It is rolling out through the Frontier programme, and customers will find it in the left navigation of the Copilot app.

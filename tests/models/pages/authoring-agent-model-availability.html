Model release types and availability labels

Release type

Release type Description
Experimental Used for experimentation, and not intended for production use. Subject to preview terms and limitations on availability and quality.
Preview Might eventually become a generally available model, but currently not intended for production use. Subject to preview terms and limitations on availability and quality.
Generally available (GA) Models without a release tag are generally available. You can use these models for scaled and production use. In most cases, generally available models have no limitations on availability and quality, but some might still have some limitations, like regional availability.

Other label

Other label Meaning
Retiring soon Still available, but will retire on a set date. Switch your agent to the replacement model before that date. To see the date and replacement for each model, see Model retirement lifecycle.
Retired No longer available. Agents that used a retired model automatically switch to its replacement model. To see the replacement for each model, see Model retirement lifecycle.
Early access environment Only available in early release cycle environments. These environments receive new updates and features first. Learn more in Early release cycle environments.
